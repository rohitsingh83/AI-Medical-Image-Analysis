Deep-learning pneumonia detection from chest X-rays · Student demo system

Upload a Chest X-Ray

Select a chest X-ray image (PNG / JPG). The CNN model will classify it as NORMAL or PNEUMONIA and highlight the regions that influenced the decision using a Grad-CAM heatmap.

🖼

How It Works

1. Preprocess Resize to 128×128, grayscale, normalize pixels to [0,1].
2. CNN Inference A convolutional network extracts visual features and outputs a probability.
3. Explain Grad-CAM highlights the lung regions driving the prediction.
Disclaimer: This is an academic demonstration trained on a virtual simulation dataset. It is not a certified medical device and must not be used for real clinical decisions.
